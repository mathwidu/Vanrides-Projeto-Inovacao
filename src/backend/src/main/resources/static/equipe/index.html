Motorista de teste da equipe

Gera um convite de passageiro em nome de um motorista fictício, com uma rotina de ida todos os dias às 07:30. Use para testar o cadastro do passageiro sem um segundo número.

Com o número liberado, envie a mensagem inteira em uma única mensagem. Se a pessoa ainda estiver sem cadastro, o próprio convite já inicia essa etapa.

Pedidos de vínculo

    Use “Atualizar pedidos” depois que o passageiro confirmar o resumo.

    Este motorista não tem WhatsApp. O que no fluxo real iria para ele (pedido novo, troca de ponto, encerramento pelo passageiro) aparece só nesta lista. O passageiro recebe pelo WhatsApp os mesmos avisos que receberia de um motorista real. Presença, saída e GPS não acontecem com este motorista.
