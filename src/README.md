# Código do MVP

- `backend/`: API Java/Spring Boot, persistência e contratos.
- `aplicativo-motorista/`: raiz Flutter, coletor Android/iOS e testes.
- `whatsapp/`: bot Node.js, adaptadores, links, fluxos n8n e ensaios.

As três pastas pertencem ao mesmo Git. Comece pelo [guia de contribuição](../CONTRIBUTING.md).
Cada módulo mantém sua raiz de build; não há dependência de clones privados.

Código anterior à experiência WhatsApp permanece quando necessário à compatibilidade
e aos testes; sua presença não amplia o escopo do MVP. O módulo de mapas adiado
e materiais de marketing não fazem parte desta execução.
