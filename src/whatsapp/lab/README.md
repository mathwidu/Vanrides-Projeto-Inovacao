# Utilitários de laboratório preservados

`live-ingress` e `live-runtime` mantêm código e testes de validação, preparação
e recuperação. A CI executa somente testes offline com fixtures sintéticas.
Manifests e hashes históricos continuam identificando as fontes antigas.
Eles não são recibos deste checkout nem uma receita atual de operação remota.
A entrada acadêmica suportada é [o guia WhatsApp](../../../docs/desenvolvimento/whatsapp.md).
