# Suporte local do receptor

`Dockerfile.gateway`, `nginx.conf`, `healthcheck.sh`, `local_smoke.sh` e
`state_backup.py` são fontes de teste do gateway/restore. Nenhum deploy de VPS
é executado pela CI acadêmica. A configuração Host foi preservada para
compatibilidade do protocolo, sem credenciais. O guia atual fica em
[WhatsApp](../../../../docs/desenvolvimento/whatsapp.md).
