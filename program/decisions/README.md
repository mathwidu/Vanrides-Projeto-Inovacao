# Decisões

Use `program/templates/DECISION.md` para decisões que alterem arquitetura,
governança, política de dados, gates ou limites de WIP.

Uma decisão aceita não substitui testes nem evidências.

- [ADR-008 — Validação remota e ambiente do piloto WhatsApp](ADR-008-remote-validation-and-pilot.md): autorização de infraestrutura, preservação dos aplicativos do proprietário e distinção entre CI, aparelho e piloto.

- [ADR-009 — MVP sem integração de navegação externa](ADR-009-whatsapp-mvp-without-navigation.md): coleta e ordem de pontos mantidas; integração Maps/Waze fora da primeira entrega.
