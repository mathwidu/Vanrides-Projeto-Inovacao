# Evidências

Esta pasta contém índices e evidências pequenas, sanitizadas e versionáveis.

Artefatos grandes, dados sensíveis, vídeos, logs completos e resultados de
ferramentas externas devem permanecer fora do Git. O card registra:

- localização;
- checksum;
- data;
- comando de reprodução;
- política de retenção;
- confirmação de que não contém segredo ou dado pessoal.

Nunca registrar senhas, tokens, cookies, GPS bruto, endereços privados ou dados
de menores.
